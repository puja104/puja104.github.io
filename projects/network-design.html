Multi-Router Network Design

Cisco Packet Tracer · Networking · Subnetting · Static Routing

Designed and configured a four-router, four-LAN network topology in Cisco Packet Tracer. The project focused on IP addressing, subnetting, router configuration, and establishing connectivity between multiple networks.

Project Overview

The goal of this project was to design a network in which multiple LAN segments could communicate across point-to-point WAN connections. Each LAN was assigned its own subnet, while /30 networks were used for point-to-point router links.

What I Built

  • Designed a four-router, four-LAN topology.
  • Created IP addressing schemes for each LAN.
  • Used /24 subnetting for LAN networks.
  • Used /30 subnetting for point-to-point WAN links.
  • Configured router interfaces using Cisco IOS CLI.
  • Enabled interfaces using the no shutdown command.
  • Configured static routes between non-adjacent networks.
  • Tested connectivity between hosts across multiple routers.

Technologies & Tools

Cisco Packet Tracer Cisco IOS IPv4 Subnetting Static Routing TCP/IP LAN/WAN

Network Configuration

Router interfaces were configured with appropriate IP addresses and subnet masks. After interface configuration, static routes were added to allow traffic to reach networks that were not directly connected to each router.

Testing & Troubleshooting

Connectivity was tested between hosts located on different LAN segments. When connectivity issues occurred, router interface status, IP addressing, subnet masks, and routing configuration were reviewed to identify the cause.

What This Project Demonstrates

  • Understanding of IPv4 addressing
  • Subnetting and network segmentation
  • Basic Cisco IOS configuration
  • Static routing
  • LAN and WAN concepts
  • Network troubleshooting
  • Logical network design
